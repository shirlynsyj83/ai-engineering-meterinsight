# GitHub Setup — MeterInsight
The Part C handout requires a public repository **only where its contents are safe for public sharing**, a README, `docs/` files, and the repository URL for submission.

1. Create a GitHub repository named **`ai-engineering-meterinsight`** at https://github.com/new.
2. Copy the extracted folder contents into the repository; check no personal or confidential data are included.
3. From the repository root run:

```bash
git add README.md .gitignore docs/ evaluation/ data/.gitkeep src/.gitkeep notebooks/.gitkeep prompts/.gitkeep
git commit -m "Week 1: MeterInsight project scope, system map, README and observation draft"
git push
```
